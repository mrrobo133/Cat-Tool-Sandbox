## 🚀 Overview

**CAT TOOL** is an advanced, lightweight Python-based local sandbox and security testing framework designed specifically for Termux and Linux environments. It simulates over 100+ major global platform templates in an isolated local environment for cybersecurity training, ethical hacking demonstrations, and developer testing.

---

## ✨ Key Features

* **100+ Platform Modules:** Built-in templates ranging from social media to cloud infrastructure and gaming portals.
* **Golden Aesthetic UI:** Eye-catching, clean golden-themed terminal interface and responsive web sandbox pages.
* **Flexible Networking:** Supports both **Localhost (`127.0.0.1`)** and **Local Network / Hotspot (LAN IP)** configurations.
* **Secure Local Logging:** Automatically routes captured test data into separate isolated logs (`usernames.txt` & `passwords.txt`).
* **Automated Installer:** Quick, interactive setup script (`install.sh`) with built-in integrity scanning and registration portal.
